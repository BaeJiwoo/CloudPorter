<h1 align="center">CloudPorter</h1>

<p align="center">웹 애플리케이션의 개발 환경을 자동으로 확인하고, 그에 맞게 배포하는 도구</p>

## 프로젝트 목표

CloudPorter의 목표는 사용자가 제공한 웹 애플리케이션의 개발 환경을 자동으로 확인하고, 확인한 환경에 맞게 배포하는 것입니다.

사용 언어, 프레임워크, 의존성, 실행 진입점과 실행 방법을 자동으로 파악하고, 이를 바탕으로 Docker 기반 배포 환경을 구성하여 로컬 또는 클라우드에 배포하는 흐름을 목표로 합니다.

사용자가 프로젝트마다 개발 환경을 직접 확인하고 배포 설정을 작성해야 하는 작업을 줄이는 것이 핵심입니다. 현재 이 목표를 향해 개발 중입니다.
