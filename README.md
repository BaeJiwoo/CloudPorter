<h1 align="center">CloudPorter</h1>

<p align="center">웹 애플리케이션을 분석하고 Docker 기반 배포를 돕는 Mini Deployer</p>

## 프로젝트 목표

사용자가 제공한 웹 애플리케이션을 분석하고, Dockerfile과 실행 방법을 결정하여 로컬 또는 클라우드에 쉽게 배포할 수 있는 도구를 만들고 있습니다.
